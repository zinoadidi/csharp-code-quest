# C# Code Quest

A free, browser-based game for learning C# from scratch. No installs, no accounts, no server — it runs entirely client-side and saves your progress on your own device.

**Play it here:** https://zinoadidi.github.io/csharp-code-quest/

## What it is

C# Code Quest walks you through C# one topic at a time, in the order most beginners actually need them: variables and types, operators, control flow, loops, arrays and collections, methods, strings, classes and objects, LINQ, and error handling — 12 levels in total, ending in a capstone project.

Each level mixes a few different ways of learning:

- **Coding tasks** — real C# you write and run in the browser (powered by Roslyn), with instant feedback and a tiered hint system that only shows you the full solution as a last resort.
- **Flashcards** — quick recall of key terms and syntax.
- **Quizzes** — multiple-choice and true/false checks that gate progress to the next level.
- **Visual tasks** — some coding tasks render their output as a live on-screen drawing, so you can see what your code actually does.

## Along the way

- **Points and streaks** for completing tasks and staying consistent.
- **Achievements** for things like finishing without hints, coming back after a break, or hitting a streak.
- **A stats page** to see your overall progress.
- **A certificate** once you complete all 12 levels.

Everything is saved locally in your browser, so you can close the tab and pick up right where you left off.

## Who it's for

Anyone starting out with C# — self-taught learners, students in a classroom setting, or anyone who wants a more hands-on alternative to reading documentation.
